# 머거바라: 가족 식단·운동 기록 웹앱 요구사항

2026-10-04 기준

## 목적과 배경

가족 4명이 매일 먹은 것과 움직인 것을 탭 몇 번으로 기록하고 하루 결과를 한눈에 보는 모바일 웹앱이다. 목표는 먹고 움직이는 것이 체중과 관련 있다는 것을 초등학생 자녀가 스스로 알게 하는 것이다. 세세한 입력과 관리는 동기를 떨어뜨리므로 넣지 않고, 가족 모두 익숙한 듀오링고의 단순하고 재미있는 흐름을 따른다.

설계 원칙은 다음과 같다.

- 기록은 탭이 기본이다. 타이핑은 목록에 없는 메뉴를 찾을 때만 한다.
- 한 끼 기록은 30초 안에 끝난다.
- 화면과 기능은 가족 모두 동일하다. 관리 수준은 부모가 옆에서 감독하고, 앱에는 잠금이나 프로필별 설정을 두지 않는다.
- 보상은 본인이 통제할 수 있는 행동(기록, 활동, 채소·과일)에만 건다.
- 앱의 말투는 항상 격려다. 체중이나 외모를 평가하는 문구는 어디에도 없다.
- 서버와 로그인 없이 정적 파일만으로 동작한다. Claude는 두 곳에서만 부르고, 키가 없어도 기록 기능은 모두 동작한다.

## 범위

v1은 기록, 하루 결과, 캘린더, 스트릭에 Claude 쓰임 두 가지를 더한 범위다.

| 하는 것 | 안 하는 것 |
| --- | --- |
| 식사·간식 기록 | 로그인, 계정 |
| 운동 기록 | 서버, 데이터베이스 |
| 체중·키 기록 | 가족 간 기록 공유, 리그 |
| 하루 결과와 규칙으로 고르는 한마디 | 문장으로 기록하기 (v2 후보) |
| 캘린더, 주간 추세, BMI 성장도표 | 푸시 알림 |
| 스트릭, 뱃지, 완료 축하 | 앱 안 캐릭터 |
| 메뉴 검색과 내 메뉴 추가 | 음식 사진 인식, 탄단지 분석 |
| Claude의 새 메뉴 추정과 주간 리뷰 | 프로필별 기능 켜고 끄기 |

## 기록 흐름

기기 1대를 1명이 쓴다. 첫 실행 때 이름과 성별을 고르고 태어난 해와 달을 숫자로 적으며, 이 값으로 하루 섭취 목표를 자동으로 추천한다.

### 식사와 간식

1. 홈에서 아침, 점심, 저녁, 간식 카드 중 하나를 누른다.
2. 최근에 먹은 메뉴와 자주 먹은 메뉴가 태그로 먼저 보인다. 누르면 추가된다.
3. 태그에 없으면 검색창에 타이핑한다. 입력하는 동안 일치하는 메뉴가 추천된다.
4. 추천에도 없는 새 메뉴는 그대로 추가한다. Claude가 1인분 칼로리와 식품군을 추정해 내 목록에 저장하고, 다음부터는 저장된 값을 쓴다. 키가 없거나 호출이 실패하면 크기를 간식 정도, 가벼운 한 끼, 보통 한 끼, 든든한 한 끼 중에서 고른다.
5. 메뉴마다 양을 1~5단계 동그라미로 고른다. 한쪽 끝이 조금, 반대쪽 끝이 많이이고 동그라미가 점점 커진다. 새로 담은 메뉴는 목록 맨 위에 나타난다.
6. 저장하면 홈으로 돌아오고 아래쪽에 짧은 완료 알림이 뜬다.

기본 메뉴는 샐러드, 삼겹살 구이처럼 흔한 것으로 200~300개를 깔아 둔다. 한식, 분식, 급식 단골, 간식, 음료를 고르게 넣는다. 메뉴마다 1인분 칼로리와 식품군 태그를 코드에 표로 넣는다. 이 표는 개발할 때 Claude Code가 한 번 만들고, 값은 근사치다. 새 메뉴의 칼로리는 Claude가 추정한 값을 쓰고, 추정하지 못했을 때는 고른 크기에 따라 150, 300, 500, 700kcal을 준다.

### 운동

1. 강도를 고른다: 가벼움, 적당함, 조금 지침, 힘듦.
2. 시간을 고른다: 10분, 20분, 30분, 60분.

운동 종류는 묻지 않는다. 강도 버튼마다 한 줄 설명을 붙인다. 가벼움은 산책처럼 숨이 편한 정도, 적당함은 숨이 조금 차는 정도, 조금 지침은 땀이 나고 말이 끊기는 정도, 힘듦은 숨이 차서 말하기 어려운 정도다.

### 체중과 키

체중과 키는 매주 일요일에 적는다. 일요일이 되면 홈에 입력 카드가 나타나고, 체중과 키는 숫자로 적는다. 하루 사이에도 체중은 0.5~1kg 오르내리기 때문에 매일 재지 않는다. 적지 않아도 나머지 기능은 그대로 동작한다.

## 계산 규칙

칼로리 합산은 전부 코드로 하고 Claude에게 맡기지 않는다. 그래야 API가 실패해도 결과가 나오고 같은 입력에 항상 같은 숫자가 나온다. Claude가 추정한 새 메뉴 값도 한 번 저장한 뒤로는 표의 값과 똑같이 쓴다.

| 항목 | 계산 |
| --- | --- |
| 섭취 | 메뉴 1인분 kcal × 양 계수의 합. 계수 초기값은 1단계부터 0.6, 0.8, 1.0, 1.2, 1.4 |
| 운동 소비 | 강도별 MET × 체중(kg) × 시간(h). MET 초기값은 가벼움 3, 적당함 4.5, 조금 지침 6, 힘듦 8. 체중을 안 적었으면 연령대 표준 체중 |
| 기준선 | 나이와 성별에 따른 에너지 필요추정량을 자동으로 추천. 설정에서 고칠 수 있다 |
| 오늘의 균형 | 섭취 − (기준선 + 운동 소비) |
| BMI | 체중(kg) ÷ 키(m)². 18세 이하는 성장도표 백분위로, 어른은 값 그대로 표시 |

기준선은 2020 한국인 영양소 섭취기준(보건복지부, `docs` 폴더의 PDF) p.29 표 17의 에너지 필요추정량을 쓰고, 체중을 적지 않았을 때의 연령대 표준 체중은 같은 문서 p.xxv 표 3 체위기준을 쓴다. 여아는 9~11세 1,800kcal, 12~14세 2,000kcal이다. 사용자에게 목표를 직접 입력하라고 요구하지 않는다.

운동만 빼면 안 되고 기준선을 함께 빼야 한다. 하루 소비의 대부분은 기초대사와 일상 활동이라서, 운동만 빼면 매일 크게 남는 것으로 나온다. 모든 값은 근사치이고 하루 숫자보다 주간 추세를 보는 용도다.

### BMI 성장도표

18세 이하는 2017 소아청소년 성장도표의 성별·월령별 기준으로 BMI 백분위를 계산한다. 월령이 필요해서 첫 실행 때 태어난 달까지 받는다. 85백분위 이상이 과체중, 95백분위 이상이 비만 구간이다([서울대병원 의학정보](https://www.snuh.org/health/nMedInfo/nView.do?category=DIS&medid=AA000081)).

- **계산**: 표에서 성별과 월령에 맞는 행을 찾고, 내 BMI가 놓인 두 백분위 열 사이를 직선으로 보간해 백분위를 구한다. 1백분위 미만과 99백분위 초과는 '1 미만', '99 초과'로 표시한다.
- **데이터**: 질병관리청 2017 성장도표의 체질량지수 백분위수 표(24~227개월, 백분위 열 13개)를 성별마다 CSV 파일로 레포에 넣고 거기서 읽는다. 기억이나 추정으로 숫자를 만들어 넣지 않는다.
- **표시**: 성장도표 곡선 위에 내 위치를 점으로 찍는다. 구간은 색 띠로만 구분하고 '비만' 같은 글자 딱지는 화면에 쓰지 않는다.

## 결과 화면과 한마디

홈에서 오늘 마감 버튼을 누르면 결과 카드가 나온다. 카드에는 섭취 kcal, 운동 소비 kcal, 오늘의 균형, 식품군 체크(채소, 과일, 단백질, 유제품을 먹었는지)가 들어간다.

하루 한마디에는 Claude를 쓰지 않는다. 미리 써 둔 문구 90개쯤(경우마다 5개 이상) 중에서 그날 기록에 맞는 것을 규칙으로 고른다.

문구를 고르고 쓰는 규칙은 다음과 같다.

- 조건별로 문구를 나눈다: 식품군 네 가지를 모두 먹은 날, 채소와 과일을 둘 다 / 채소만 / 과일만 먹은 날, 단백질과 유제품을 먹은 날, 60분 이상 / 30분 이상 / 짧게 움직인 날, 힘든 강도로 운동한 날, 세 끼를 모두 기록한 날, 아침을 먹은 날, 연속 기록 2일 / 7일 / 30일 이상, 처음 기록한 날, 주말, 그 밖의 날.
- 조건이 여러 개 맞으면 그중 하나를 무작위로 고른다.
- 섭취가 목표의 70%에 못 미치면 칭찬 대신 더 먹으라는 문구를 보여준다. 70%는 초기값이다.
- 체중, 몸매, 외모는 언급하지 않는다.
- 음식에 좋다, 나쁘다는 딱지를 붙이지 않는다.
- 끼니를 거르거나 굶으라고 권하지 않는다.

## Claude가 하는 일

Claude는 규칙으로 할 수 없는 두 가지만 맡는다. 키가 없거나 호출이 실패해도 앱은 멈추지 않는다.

| 쓰임 | 보내는 것 | 받는 것 | 호출 시점 | 실패하면 |
| --- | --- | --- | --- | --- |
| 새 메뉴 추정 | 메뉴 이름 | 1인분 kcal, 식품군 태그 | 새 메뉴를 추가할 때 1회 | 크기 4단계 고르기 |
| 주간 리뷰 | 지난주(일~토)의 식사, 운동, 균형 요약 | 패턴 하나와 다음 주에 해볼 것 하나, 3~4문장 | '내 기록' 화면의 '지난주 돌아보기' 버튼을 누를 때, 주 1회. 놓친 주는 캘린더에서 그 주를 열 때 | 주간 그래프만 표시 |

공통 규칙은 다음과 같다.

- 모델은 가장 저렴한 최신 모델을 쓰고, 모델 이름은 코드 상단의 상수 하나로 둔다.
- 한 번 받은 결과는 로컬 스토리지에 저장하고 같은 것을 다시 부르지 않는다.
- 이름, 체중, 키는 Claude에 보내지 않는다.
- 새 메뉴 추정은 JSON으로 받는다. kcal가 10~1,500 범위를 벗어나면 버리고 크기 4단계 고르기로 넘어간다.

주간 리뷰는 아이가 바로 읽는 글이라 지시문에 다음 규칙을 고정한다.

- 초등학생이 읽는 따뜻하고 친근한 말투로 쓴다.
- 기록에서 보이는 패턴 하나를 구체적으로 짚고, 다음 주에 해볼 행동 하나를 제안한다.
- 체중, 몸매, 외모는 언급하지 않는다.
- 덜 먹으라거나 끼니를 거르라는 제안은 하지 않는다. 제안은 더하기(채소 한 가지 더, 10분 더 움직이기)나 바꾸기(간식 시간 옮기기)로 한다.
- 음식에 좋다, 나쁘다는 딱지를 붙이지 않는다.
- 기록이 3일 미만인 주는 Claude를 부르지 않고, 기록을 권하는 고정 문구를 보여준다.

## 캘린더와 진척도

캘린더 한 화면에서 식단, 활동, 체중을 함께 본다.

- 월 캘린더의 날짜마다 식사 기록과 운동 기록 여부를 아이콘으로 표시한다. 체중을 잰 날에는 점을 찍는다.
- 캘린더 아래에 그 달의 날짜별 먹은 에너지와 운동 시간을 선 그래프 두 개로 보여준다. 단위가 달라서 같은 날짜 칸에 맞춰 위아래로 붙여 그린다.
- 날짜를 누르면 그날의 식사, 운동, 결과 카드가 열린다.
- 캘린더 아래에 주간 그래프를 둔다. 주간 평균 균형을 막대로, 체중을 선으로 한 화면에 겹쳐 그린다. 먹고 움직인 것과 체중이 함께 움직이는 것을 보여주는, 이 앱의 핵심 화면이다.
- 주간 그래프 아래에 Claude의 주간 리뷰를 둔다. 지난주 기록에서 보인 패턴 하나와 다음 주에 해볼 것 하나를 알려준다. 한 주는 일요일에 시작해 토요일에 끝난다. 리뷰는 주마다 저장해 두고, 캘린더에서 지난 주를 고르면 그 주의 리뷰를 언제든 다시 볼 수 있다.
- 기록이 3~4주 쌓이기 전에는 관계가 잘 보이지 않는다. 그동안은 그래프 자리에 기록이 쌓이는 중이라고 안내한다.
- 18세 이하는 BMI 성장도표 위의 내 위치도 함께 보여준다.
- 월간 요약 한 장을 둔다. 기록한 날 수, 평균 섭취, 운동 횟수와 시간, 체중과 키 변화를 담고, 진료 때 그대로 보여줄 수 있게 한다.

체중이 줄었을 때 축하 연출은 하지 않는다. 체중은 본인이 바로 통제할 수 없는 값이라, 줄 때 축하하면 늘어난 주에는 벌처럼 느껴진다. 추세선으로만 보여준다.

## 게임화

듀오링고에서 가져오는 것은 스트릭, 짧은 세션, 완료 축하 세 가지다.

- **스트릭**: 하루에 식사를 한 건이라도 기록하면 이어진다. 무엇을 얼마나 먹었는지는 상관없다.
- **연속 기록 진척**: 프리즈 같은 보호 장치는 두지 않는다. 대신 홈에 최근 7일 기록 칸과 다음 목표(3, 7, 14, 30, 50, 100일 연속)까지 남은 날을 막대로 보여주고, 뱃지 화면에 최근 5주 기록 칸을 둔다.
- **뱃지**: 첫 기록, 7일 연속, 30일 연속, 채소 먹은 날 5일, 60분 움직인 날처럼 행동에만 준다. 적게 먹은 것과 체중에는 주지 않는다.
- **홈 인사말**: 홈 맨 위에는 미리 써 둔 응원 문구 30개를 섞어서 들어올 때마다 하나씩 보여준다. 문구 규칙은 하루 한마디와 같다.
- **완료 알림과 마감 축하**: 기록을 저장할 때는 짧은 알림과 효과음만 나온다. 효과음은 설정에서 켜 두면 기기의 무음 모드에서도 들린다. 색종이 축하 화면은 하루를 마감할 때만 나온다.
- **지난 날 마감**: 결과를 보지 못하고 날짜가 바뀌어도 기록은 그대로 남는다. 어제 기록이 있고 마감하지 않았으면 홈에 '어제 결과' 카드가 떠서 어제를 마감하고 결과를 볼 수 있다.
- **화면 톤**: 큰 버튼, 둥근 모서리, 한 화면에 한 가지 일, 위쪽에 진행 막대.
- **이름, 아이콘, 색**: 서비스 이름은 '머거바라'다. 준비해 둔 카피바라 그림을 앱 아이콘으로 쓰고, 홈 화면 아이콘 이름과 앱 상단에 카피바라 얼굴과 함께 '머거바라'를 표시한다. 화면 색은 아이콘 배경의 노란색을 기본으로 하고, 털의 갈색과 풀의 초록색을 포인트로 쓴다. 정확한 색 값은 아이콘 파일에서 뽑는다. 앱 안에는 캐릭터를 두지 않는다.

## 저장, 배포, API 키

빌드 과정 없이 정적 파일만으로 동작하고 GitHub Pages에 올린다.

- **최신 버전 가져오기**: 홈 화면 아이콘으로 쓰면 새로고침 버튼이 없으므로, 설정 맨 아래에 버전 표시와 '최신 버전 가져오기' 버튼을 둔다. 기록은 그대로 남는다.
- **저장**: 브라우저 로컬 스토리지에 저장한다. 내가 추가한 메뉴도 여기에 둔다. 설정에 JSON 내보내기와 가져오기 버튼을 둔다.
- **홈 화면에 추가**: 홈 화면 아이콘으로 실행되도록 매니페스트를 넣는다. 사파리는 오래 쓰지 않은 사이트의 저장 데이터를 지울 수 있어서, 홈 화면에 추가해 쓰는 것을 전제로 한다.
- **API 키**: 코드와 레포에 넣지 않는다. 부모가 각 기기의 설정 화면에서 한 번 입력하고 로컬 스토리지에 둔다. 공개 레포에서 키가 감지되면 [Anthropic이 자동으로 비활성화](https://support.claude.com/en/articles/9767949-api-key-best-practices-keeping-your-keys-safe-and-secure)하기 때문이다.
- **키 노출 줄이기**: 입력한 키는 화면에 다시 보여주지 않고, JSON 내보내기에도 넣지 않는다.
- **전용 키와 한도**: 이 앱 전용 키를 따로 만들고 Claude 콘솔에서 사용 한도를 낮게 건다. 키가 새어도 피해가 한도 안에서 끝나고 그 키만 폐기하면 된다.
- **호출 방식**: 브라우저에서 Messages API를 직접 부른다. 요청에 `anthropic-dangerous-direct-browser-access: true` 헤더를 넣으면 [서버 없이 호출](https://simonwillison.net/2024/Aug/23/anthropic-dangerous-direct-browser-access/)할 수 있다.
- **개인정보**: 레포에는 가족 이름과 건강 정보를 넣지 않는다. 이름은 각자 기기에서 입력한 값만 쓴다.
